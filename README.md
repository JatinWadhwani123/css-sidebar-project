📸 Photography Sidebar Menu – HTML & CSS Project

This is a simple yet elegant Sidebar Navigation Menu UI designed for a Photography-themed website, built using only HTML and CSS — no JavaScript! It features smooth animations, responsive layout, and stylish icon integration using Font Awesome.
✨ Features

    ✅ Sidebar toggle using pure HTML checkbox (no JS)

    🖼️ Full-page background image (photo.jpg)

    🎨 Modern UI using Google Fonts (Poppins)

    📱 Responsive and interactive menu items

    💬 Social media icons with hover effects

    ⚡ Smooth transition and shadow effects

💡 Use Case

This layout can be used for:

    Photography or portfolio websites

    Minimal sidebar-based web templates

    Learning HTML/CSS layout techniques

📁 Files Included

    index.html — Main HTML structure

    style24.css — Styling with transitions and hover effects

    photo.jpg — Background image (replaceable)
